# Курс по автоматизации тестирования с помощью Selenium и Python (Stepik)

Репозиторий содержит решения практических заданий и автотестов для курса «Автоматизация тестирования с помощью Selenium и Python» на Stepik (курс №575).

## Структура репозитория

- `1.*.py` — Задания модуля 1 (Знакомство с Selenium WebDriver, поиск элементов, базовые сценарии).
- `2.*.py` — Задания модуля 2 (Работа с выпадающими списками, alert/confirm/prompt окнами, переключение вкладок, JavaScript-скрипты и явные ожидания WebDriverWait).
- `conftest.py` — Конфигурация PyTest с обработчиком параметров командной строки `--language` и фикстурой браузера `browser`.
- `test_items.py` — Тест для проверки наличия кнопки добавления товара в корзину на разных языках.
- `test_stepik_quest.py` — Параметризованный тест с авторизацией на Stepik для проверки динамических ответов и фидбека.
- `test_registration.py`, `3.2.13.py` — Тесты формы регистрации с использованием unittest / pytest.

## Запуск финального теста задания (Шаг 3.6.10)

Тест запускается с указанием языка через параметр `--language`:

```bash
pytest --language=es test_items.py
```

Для проверки других языков (например, французского `fr`):

```bash
pytest --language=fr test_items.py
```
